# 🏗️ معمارية THE WAY OUT — خارطة التطوير (v1 → v10)

> تصميمات مستقبلية معتمدة من المحادثات السابقة — تُنفَّذ تدريجياً حسب أولويات `ROADMAP.md`.
> القاعدة: كل نسخة يجب أن تبقى **شغالة محلياً** على Windows + Ollama قبل الانتقال للتالية.

## الوضع الحالي: v1.1 — الإيجنت الموحد (Single-File Agent)

```
┌─────────────┐   عربي   ┌──────────────┐  tool_calls  ┌─────────────────┐
│  المستخدم   │ ───────▶ │ agent.py CLI │ ───────────▶ │ Ollama 1.5b     │
│ (PowerShell)│ ◀─────── │  + 7 Tools   │ ◀─────────── │ localhost:11434 │
└─────────────┘  تقرير   └──────┬───────┘   قرارات     └─────────────────┘
                                │ تنفيذ محلي
                    ┌───────────┼───────────┐
                    ▼           ▼           ▼
                 نظام الملفات  التيرمينال  الويب/المنافذ
```

- ملف واحد `agent.py` — بدون تعقيد، مناسب لجهاز ضعيف وموديل 1.5b.
- 7 أدوات: `execute_terminal` / `write_file` / `read_file` / `list_files` /
  `launch_the_way_out` / `read_website` / `check_port`.

## v2.0 — محرك التفكير ReAct + تصحيح ذاتي (Self-Correction)

- حلقة **Reason → Act → Observe** صريحة في الـ system prompt.
- إعادة المحاولة التلقائية عند فشل أداة (حتى N مرات مع تعديل الباراميترات).
- سجل خطوات منظم يُحفظ في `runs/<timestamp>.json` للمراجعة.

## v3.0 — ذاكرة طويلة المدى (Memory)

- **ذاكرة قصيرة:** آخر K رسالة في الجلسة (موجودة جزئياً).
- **ذاكرة دائمة:** ملف `memory.json` يحفظ حقائق عن المستخدم والمشروع.
- **لاحقاً:** Vector Memory (ChromaDB محلي) + Entity Graph للعلاقات.

## v4.0 — مهارات الويب والعمل الحر (Web Skills)

- `read_website` عميق: تتبّع روابط + استخراج وظائف/مشاريع بهيكل JSON.
- Browser Agent عبر `playwright`: أتمتة تصفح مستقل / Upwork
  (بحث، فلترة، استخراج تفاصيل المشاريع — **بدون تقديم تلقائي** إلا بموافقة المستخدم).
- جدولة: فحص دوري للفرص الجديدة + تنبيه.

## v5.0 — بروتوكول MCP (Model Context Protocol)

- تغليف الأدوات كـ MCP Servers قياسية:
  `filesystem-server` / `terminal-server` / `web-server`.
- يتيح ربط نفس الأدوات بأي عميل MCP (Claude Desktop، Continue ... إلخ).

## v6.0 — RAG على ملفات المستخدم

- فهرسة مجلدات المستخدم (مشاريع، CV، مستندات) في ChromaDB محلي.
- أداة `search_knowledge("...")` يلجأ لها الإيجنت قبل الإجابة عن أسئلة المشروع.
- تضمين محلي عبر Ollama (`nomic-embed-text`) — بدون API خارجي.

## v7.0 — واجهة ويب (Web UI)

- Backend: `FastAPI` + Streaming (SSE) لعرض التفكير والأدوات لحظة بلحظة.
- Frontend: صفحة واحدة (عربي RTL) — شات + سجل تنفيذ + إدارة ملفات.
- تبقى الـ CLI شغالة بالتوازي (نفس `agent.py` كـ core).

## v8.0 — الترقية للموديلات الأكبر

- عند توفر 16GB+ RAM: الترقية إلى `qwen2.5-coder:7b` ( tool-calling أدق بكثير).
- دعم التبديل بين موديلات (`--model`) + مقارنة جودة.
- Quantized بدائل خفيفة للتجربة (`qwen3`, `deepseek-coder`).

## v9.0 — تعدد الوكلاء (Multi-Agent)

- **مخطط (Planner):** يفكك المهمة الكبيرة لمهام صغيرة.
- **منفّذ (Executor):** ينفذ كل مهمة بالأدوات.
- **مراجع (Reviewer):** يفحص النتائج ويطلب إصلاحات.
- تنسيق عبر ملفات/طابور محلي بسيط (بدون سيرفرات خارجية).

## v10.0 — منصة متكاملة (Platform)

- كل ما سبق + Copilot للأكواد + لوحة مراقبة للخدمات والمنافذ.
- حزم تثبيت (`setup.ps1` شامل) + تحديث تلقائي من Git.
- توثيق عربي كامل + فيديو شرح.

## مبادئ ثابتة عبر كل النسخ

1. **محلي أولاً:** لا يعتمد على إنترنت أو API مدفوع في الوظائف الأساسية.
2. **تدريجية:** كل نسخة شغالة ومُختبَرة قبل التالية (`--check` أخضر).
3. **أمان:** فلتر الأوامر + `.env` للأسرار + عدم تنفيذ ما لم يُطلب صراحةً.
4. **عربي:** الواجهة والتقارير بالعربية — الأكواد بالإنجليزية النظيفة.
