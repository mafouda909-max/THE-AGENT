# 🗺️ خطة العمل — THE WAY OUT Agent

> مرتبة بالأولوية — تُحدَّث بعد كل جلسة عمل.

---

## 🔴 أولوية قصوى — التشغيل الأول على جهاز المستخدم

- [ ] فتح PowerShell والدخول لمجلد `the_way_out`.
- [ ] `pip install -r requirements.txt`.
- [ ] `python agent.py --check` → كل الفحوصات خضراء (عدا Ollama/الإنترنت حسب التوفر).
- [ ] `python agent.py` → التأكد من سطر `🔌 Ollama: متصل — الموديل جاهز ✅`.
- [ ] تجربة أمر عربي بسيط: `اكتب ملف hello.py يطبع السلام عليكم ثم اقرأه`.

**معيار القبول:** الإيجنت ينفذ أداتين على الأقل (`write_file` + `read_file`) ويرد بالعربي.

---

## 🟠 أولوية عالية — اختبار المهارات الحية

- [ ] `شغّل مشروع THE WAY OUT` → يفتح `http://localhost:5000` في المتصفح ويعرض الرسالة.
- [ ] `افحص المنفذ 5000` → يرد بأن الخدمة شغالة.
- [ ] `اقرأ موقع https://example.com ولخصه` → يعرض ملخصاً عربياً.
- [ ] `نفّذ أمر dir` → يعرض محتويات المجلد.
- [ ] إيقاف السيرفر عند الخروج من الإيجنت (تنظيف تلقائي).

**معيار القبول:** 4 من 5 مهارات تعمل من أول محاولة بالأوامر العربية.

---

## 🟡 أولوية متوسطة — أتمتة تصفح متقدمة (Playwright)

- [ ] تثبيت `playwright` + متصفح Chromium محلي.
- [ ] أداة `browse_jobs(site, query)`: بحث في موقع عمل حر وإرجاع قائمة مشاريع (JSON).
- [ ] فلترة النتائج (ميزانية، مهارات) + حفظها في `jobs.md`.
- [ ] ⚠️ **ممنوع التقديم التلقائي** — الاستخراج والعرض فقط إلا بموافقة صريحة.

**معيار القبول:** `ابحث عن مشاريع بايثون في موقع مستقل` يرجع قائمة من 5+ مشاريع حقيقية.

---

## 🟢 أولوية لاحقة — واجهة ويب (Web UI)

- [ ] `server.py` بـ FastAPI يعيد استخدام `agent.py` كـ core.
- [ ] صفحة شات عربية (RTL) + عرض خطوات الأدوات لحظة بلحظة (SSE streaming).
